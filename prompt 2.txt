## 1. Complete user flow

Your main flow should be:

```text
LANDING PAGE
     ↓
User selects what they want
     ↓
┌─────────────────┬──────────────────┐
│ Find a Place    │ Find a Flatmate  │
└─────────────────┴──────────────────┘
     ↓
Explore Listings / Create Profile
     ↓
View Listing
     ↓
Login required to Chat
     ↓
Start Conversation
     ↓
Find Match
     ↓
Mark Listing as Closed
```

The most important thing is: **a visitor should be able to browse without creating an account**.

Only require login when they:

* Post a listing
* Chat with someone
* Save a listing
* Report a user

This reduces friction.

# 14. Important API design

Since Android comes later:

```text
Web Frontend
      │
      ▼
REST / API Backend
      │
      ├── Authentication
      ├── Users
      ├── Listings
      ├── Search
      ├── Chat
      ├── Notifications
      └── Admin
              │
              ▼
          PostgreSQL
```

Your website should **never directly depend on the database structure from the frontend**.

Build proper APIs from day one.

# What I would do next

Before starting development, create these **four deliverables**:

1. **Product name and branding**
2. **Complete database schema**
3. **API specification**
4. **Premium website UI design**

Then development becomes much easier because there is no confusion about what Claude Code or another AI coding tool should build.

I suggest we now start with **Step 1: choosing the product name + defining the brand and premium UI direction**, and then move to the exact database schema and development prompt.
